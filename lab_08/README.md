# Лабораторная работа № 8. Динамические массивы и std::vector

**Вариант 4.** Фильтрация: сохранить в отдельный vector только числа, кратные 3,
из введённой последовательности неизвестной длины.


## Ч1. Проблема фиксированного размера массива

В части Ч1 читаем числа в массив фиксированной длины `kFixedSize = 5`.
Если пользователь введёт больше 5 чисел, лишние значения **не поместятся**
в массив: в лучшем случае мы их отбросим с предупреждением, в худшем —
при наивной записи без проверки `count < kFixedSize` произойдёт **выход за
границы массива** (undefined behavior): запись в чужую память, порча стека,
возможное падение программы. Размер обычного массива фиксируется на этапе
компиляции, поэтому заранее неизвестное количество данных — прямая проблема.
Именно её решает `std::vector`.

## Ч3. Операции vector и поведение при выходе за границы

- `size()` возвращает количество реально хранимых элементов.
- `capacity()` — сколько элементов помещается в уже выделенной памяти.
  `capacity() >= size()`, и после `push_back` capacity может вырасти с запасом
  (амортизированное O(1) на добавление).
- `at(i)` **проверяет границы** и бросает `std::out_of_range` при `i >= size()`.
  В программе это исключение поймано в `try/catch` и выведено сообщение.
- `operator[](i)` границы **не проверяет**: при `i >= size()` это UB,
  поэтому в демонстрации он не вызывается.
- `pop_back()` удаляет последний элемент (size уменьшается на 1).
- `erase(it)` удаляет элемент по итератору, сдвигая последующие влево
  (O(n)). Важно: `erase` инвалидирует итераторы, поэтому внутри цикла
  нужно переприсваивать итератор результатом `erase`.

## Ч4. Псевдоним типа

Введён `using Numbers = std::vector<double>;`. Он используется в сигнатурах
`readVector`, `filterMultiplesOfThree`, `printVector` — то есть реально,
а не только объявлен.

## Ч5. Решение варианта 4

Функция `filterMultiplesOfThree` проходит по исходному вектору и складывает
в новый `Numbers` только целые значения, кратные 3. Исходная
последовательность читается через `push_back` (Ч2), поэтому её длина
заранее неизвестна — фиксированный массив не используется.
