## Ч1. Почему `побочныйЭффект()` вызывается не всегда

Оператор `&&` сначала вычисляет **левый** операнд. Если он **ложный**,
правый операнд вообще не вычисляется — итог уже ясен (`false`). Это и есть
*short-circuit evaluation*.

Аналогично `||`: если **левый** операнд **истинный**, правый не вычисляется,
потому что результат уже `true`.

В программе это видно по строкам `[вызвана функция ...]`: при `a > 1000 && ...`
(когда a ≤ 1000) правая часть не печатается, а при `a > -1000 && ...` — печатается.
Для `||` всё зеркально.

Практический смысл: short-circuit защищает от лишних вычислений и от ошибок
(например, `if (p != nullptr && p->x > 0)` безопасен, потому что при `p == nullptr`
разыменование не выполняется).

## Ч2. Сравнение `if/else` и `switch`

Обе конструкции дают одинаковый результат для целочисленной оценки 1–5.
- `if/else` удобнее, когда условия — это **диапазоны** (`оценка >= 4`).
- `switch` читается нагляднее для **фиксированного набора** значений и явно
  показывает, что все варианты равноправны.
- В `switch` важен `break`: без него произойдёт «проваливание» в следующий `case`.

## Ч3. Почему for и while дают одинаковый результат

Оба цикла перебирают числа `2, 3, 4, ...` и останавливаются, когда найдено N простых.
В `for` счётчик и условие заданы в заголовке, в `while` — вручную.
Логика одна и та же, поэтому выводы совпадают.

## Ч4. Как заполняется массив

Массив фиксированной длины `const int РАЗМЕР = 10;` заполняется **вводом с клавиатуры**.
Среднее считается как `сумма / РАЗМЕР` (вещественное деление).
Элементы, строго большие среднего, подсчитываются отдельным проходом.

## Ч5. Совершенное число

Число совершенно, если сумма его **собственных** делителей (без самого числа)
равна ему. Например: `6 = 1 + 2 + 3`, `28 = 1 + 2 + 4 + 7 + 14`.
Делители ищутся до `sqrt(N)`, парный делитель добавляется отдельно
(и не дублируется, если `d == N/d`).

## Ч6. Сортировка обменом

Два вложенных цикла: внешний — число проходов, внутренний — сравнение соседей
`копия[j]` и `копия[j+1]`. Если левый больше — меняем местами и увеличиваем
счётчик обменов **внутри** `if`, ровно там, где происходит обмен.
